# Linux basics

## Goal
Practice core commands on my own machine and note what each one does.

## Commands I used
- `pwd` shows the current folder
- `ls` lists files
- `cd` changes folder
- `mkdir` makes a folder
- `whoami` shows the current user
- `chmod` changes file permissions

## What I learned
The terminal is just another way to manage files. Permissions decide who can read, change, or run a file.
